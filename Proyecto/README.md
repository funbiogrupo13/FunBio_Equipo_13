# GripFlex
**Descripción General**: GripFlex es una órtesis electromagnética portátil diseñada para asistir el agarre palmar de la mano derecha sobre la empuñadura de un andador mediante un sistema controlado de actuación magnética.

**Estructura:**
El contenido técnico del proyecto está organizado en las siguientes carpetas principales:
- *Módulo Software:* Contiene el código fuente de control del sistema para la gestión de activación y seguridad térmica.
- *Módulo Electrónico:* Incluye el diagrama esquemático desarrollado en EasyEDA Pro para visualizar las conexiones eléctricas y la distribución de los componentes.
- *Módulo Mecánico:* Reúne los archivos CAD, las piezas diseñadas para impresión 3D y las especificaciones detalladas de manufactura aditiva.

**Consideraciones Generales:**
Revisar la documentación específica dentro de cada subcarpeta antes de proceder con la fabricación, el cableado o la carga del programa.Verificar el correcto aislamiento eléctrico y la firmeza de los acoples mecánicos antes de realizar pruebas de operación con el prototipo.
